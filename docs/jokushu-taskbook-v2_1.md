# 蓐収株式会社官网开发任务书 v2

## 0. 文档定位

本文档是蓐収株式会社第一版官网的开发执行指令。

本文档的所有内容均派生自一个唯一权威来源：

> **《蓐収株式会社｜品牌與網站策劃文檔》定稿版 v1.0（2025 年 4 月）**
>
> 文件名：`docs/蓐収株式会社_品牌與網站策劃文檔_定稿版.md`

**优先级铁律：**

1. 策划定稿——最高权威，不可违背
2. 本任务书——策划定稿的开发翻译，逐条标注出处
3. 现有代码——仅在不与上两者冲突时保留

**如果本任务书与策划定稿发生矛盾，以策划定稿原文为准。**

本文档不会凭空新增任何策划定稿中不存在的品牌概念、服务体系或视觉决策。唯一的补充来源是日本商业网站的法务合规要求（隐私政策、特商法等），这些补充会明确标注为「法务补充」而非策划内容。

## 6. 视觉系统

**总原则（策划 §4.1）：像一本宋代刻本古籍。**

以下所有变量、规则直接搬自策划第四章，开发者应将这些值原样写入 `src/styles/global.css` 或 `src/styles/tokens.css`。

### 6.1 色板（策划 §4.2）

```css
:root {
  /* 纸色系 */
  --paper-main:    #F5EFE3;   /* 素绢米白：主背景 */
  --paper-deep:    #EDE5D2;   /* 深绢色：引用框、区块分隔 */
  --paper-dark:    #DDD2BB;   /* 暗绢色：仅藏品卷三 */
  --paper-edge:    #C9BCA0;   /* 纸边色：极淡分隔线 */

  /* 墨色系 */
  --ink-main:      #1F1A15;   /* 徽墨黑：主要文字 */
  --ink-mid:       #3A332B;   /* 中墨灰：次要文字 */
  --ink-light:     #6B5C4E;   /* 淡墨灰：辅助说明 */
  --ink-faint:     #9E8C7A;   /* 微墨灰：占位、极淡标签 */

  /* 强调色 */
  --accent-red:    #A0522D;   /* 赭石红：题识、重点词、hover */
  --accent-gold:   #B89968;   /* 金箔黄：极少量点缀 */

  /* 边框 */
  --border-faint:  rgba(31,26,21,0.08);
  --border-line:   rgba(31,26,21,0.18);
}
```

**绝不使用的颜色：** 纯黑 #000000、纯白 #FFFFFF、旧任务书的深墨 #11100E、旧任务书的古金 #C6A15B、旧任务书的暗红 #7A1F1F。

### 6.2 字体（策划 §4.3）

```css
:root {
  --font-zh-serif: "Noto Serif SC", "Source Han Serif SC", serif;
  --font-ja-serif: "Noto Serif JP", "Source Han Serif JP", serif;
  --font-en-serif: "Cormorant Garamond", serif;
  --font-mono:     "JetBrains Mono", monospace;
}
```

规则：

- **全站只用衬线体**。标题、正文、按钮、导航——全部 serif。
- 字重只用 400（regular）和 500（medium），**绝不使用 700（bold）**。
- 所有「重点」由赭石红色彩或字级承担，不依靠加粗。
- 英文字体仅用于「JOKUSHU CO., LTD.」。

### 6.3 字级（策划 §4.3）

```css
:root {
  --size-display:  3.5rem;   /* 首页「蓐収」二字 */
  --size-h1:       2rem;     /* 页面主标题 */
  --size-h2:       1.5rem;   /* 区块标题 */
  --size-h3:       1.25rem;  /* 子区块标题 */
  --size-body:     0.95rem;  /* 正文（略小于 16px，呼应书本感） */
  --size-small:    0.825rem; /* 辅助文字 */
  --size-tiny:     0.72rem;  /* 页脚、版权 */

  --leading-tight:   1.4;
  --leading-normal:  1.75;
  --leading-relaxed: 2.0;

  --tracking-wide:   0.05em;
  --tracking-wider:  0.1em;
}
```

### 6.4 版式（策划 §4.4）

```css
:root {
  --max-content: 640px;   /* 主内容宽度 */
  --max-wide:    960px;   /* 藏品列表页 */
  --max-page:    1140px;  /* 首页、总览页 */
  --gutter:      5%;
}
```

区块间距：首页屏与屏之间 **8rem**；源流章节之间 **8rem**；首页第六屏前 **12rem**。

### 6.5 组件样式（策划 §4.5）

**按钮：** 透明底、1px 实线边框、直角（border-radius: 0）、hover 时边框和文字变赭石红。禁止圆角、阴影、渐变、加粗、图标。

**表单字段：** 透明底、仅下划线、focus 时下划线变赭石红。禁止框线、圆角、内阴影、placeholder。

**链接：** 墨色文字 + 极淡下划线，hover 时变赭石红。

**分隔线：** 只有两种——48px 短横线（章节间）和 100% 长横线（区块间），都是 1px。

**章节标记：** 居中的「─ 引 ─」「─ 释 ─」样式，用 flex 居中排列。

### 6.6 动效（策划 §4.6）

**允许的：**

- 滚动淡入（opacity + translateY，0.7s，IntersectionObserver 触发）
- hover 颜色过渡（0.3s）
- 首页「蓐収」书法字 SVG 书写动画（stroke-dasharray，2.5s，仅首次访问播放）

**禁止的：** 视差滚动、轮播图、粒子效果、鼠标跟随、旋转、弹跳、闪烁、自动播放。

### 6.7 响应式（策划 §4.8）

移动端优先。断点：768px（平板）、1024px（桌面）、1440px（大屏）。首页全屏显示不变。

## 8. 语言切换（策划 §2.5，本任务书修订）

> **修订说明：** 策划定稿 §4.4 原定「中日双语上下排列」。经实际页面验证，上下排列使页面长度翻倍且一半内容对访客无用，与「宋代刻本」的阅读体感冲突。本任务书修订为全站语言切换模式——同一时间只显示一种语言，通过右上角「中｜日」切换。此修订经用户确认。

| 规则 | 值 |
|---|---|
| 默认语言 | 日文（公司为日本法人） |
| 切换方式 | 右上角「中｜日」，当前语言高亮（赭石红） |
| 首次访问 | 根据浏览器 Accept-Language 自动判断 |
| 内容对等 | 中日版本分别撰写，不是机翻 |
| URL 策略 | 第一版用客户端状态切换（不改 URL），后续迭代再做 /zh/ 路由 |
| 暗黑模式 | 不提供（策划 §2.5：「纸本气质与暗黑模式天然冲突」） |

### 8.1 切换行为

- 全站同一时间只显示一种语言，不做中日上下排列
- 切换时隐藏当前语言的所有文本块、显示目标语言的对应文本块
- 标题、正文、按钮文字、引言、列举项、表单标签全部切换
- 导航项（源流 / 奉事 / 文錄 / 藏品 / 通信）和品牌名「蓐収」不变（中日共用）
- 语言状态保存至 `localStorage`，下次访问时恢复

### 8.2 实现方式

- `Layout.astro` 中维护全局语言状态脚本（已有基础）
- 页面组件中，每个文案块用 `data-lang="zh"` / `data-lang="ja"` 属性标记
- 切换时用 CSS class（如 `lang-zh` / `lang-ja` 在 `<html>` 上切换）控制显隐
- JSON 文件的 `zh` / `ja` 字段结构不变，渲染时两个版本都输出到 DOM，但只显示当前语言对应的块

### 8.3 不切换的元素

以下元素在两种语言下保持不变：

- 品牌名「蓐収」
- 公司英文名「JOKUSHU CO., LTD.」
- 导航项文字（源流 / 奉事 / 文錄 / 藏品 / 通信）
- 页脚公司信息
- 法务页面（日文单语，不做中文版——日本法务文书以日文为准）
