## 卷首語

本文檔是蓐収株式会社的品牌與網站策劃定稿，目的是將一個有近八百年家學承傳、橫跨儒道兩系、立足大阪的玄學文化企業，通過一個極具敬畏感的數位門戶，準確、完整、不偏移地呈現出來。

文檔分五章，由淺入深——

第一章定品牌的「氣口」，從「蓐収」這個名字的釋義開始，建立整個敘事的基調與語感；第二章定網站的骨架，以「五進院落」隱喻組織六個主要頁面；第三章是肉身，提供所有頁面的完整中日雙語文案；第四章是皮相，定義配色、字體、版式、動效的精確規範；第五章是執行，提供技術選型與完整的交付包清單。

本文檔的設計目標是——任何具備合格技術能力的編碼者，拿到這份文檔，都應該能完整執行而不需要再來追問內容問題。

## 第一章 ｜ 品牌敘事核心

### 一、關於「蓐収」這個名字

**蓐収（じょくしゅう ／ Rù Shōu）**——金神之名，秋之主宰。

《禮記·月令》：「孟秋之月，其神蓐収。」《山海經》言其「左耳有蛇，乘兩龍」，司金、司秋、司刑殺、亦司收成。秋天萬物斂藏，金氣肅穆，蓐収居西方之位，於繁華落盡時行守護之責。

**選此名的理由**——

「収」是「收」，是收成、收斂、收歸。  
是承接前人所留，亦是為後人收藏所守。  
是季節輪轉中，最沉靜也最莊重的那一刻。

蓐収不是繁盛之神，而是**守護者**。  
不為招攬而存在，只為**該被守護的人事物**而立。

### 三、品牌 Voice & Tone

#### Voice（氣質）：清、靜、敬、信

- **清**——不蕪雜，不堆砌，能用一句話說清楚的不寫兩句
- **靜**——不熱鬧，不熱情邀約，留白比說話多
- **敬**——對所承之物敬，對所遇之人敬，自稱與他稱皆有分寸
- **信**——不誇張，不承諾運勢、不保證結果，只說所做之事與所守之則

#### Tone（語調）：

**避免使用：**

- 「歡迎來到...」「我們致力於...」「您將獲得...」這類網站套話
- 「立即預約」「馬上聯繫」「不容錯過」這類促銷感詞彙
- 「最專業」「最權威」「業界領先」這類自誇式形容
- 過度使用感嘆號、emoji、強調色加粗
- 任何對運勢、財運、命運的具體承諾

**鼓勵使用：**

- 古意但不晦澀的雅言（「如有所需，可遣信來」「不時之需，可備諮詢」）
- 短句，留白，省略可省的字
- 客觀陳述（「我們做這件事」「這項服務涉及這些內容」），把判斷權交給讀者
- 「可」「或」「不時」「若」這類留有餘地的詞

### 四、文案範例對照

下面三組是同一個意思的兩種寫法，幫助校準語感：

**範例一｜首頁 hero 文案**

普通寫法：

> 蓐収株式会社是一家專業的玄學諮詢公司，我們致力於為您提供最優質的風水、命理服務，立刻預約您的專屬諮詢吧！

蓐収氣口：

> 蓐収為金神，主秋，主守護。
> 我們承家學，習師門，以所知所守，為遇見之人立一方安處。

日文對等：

> 蓐収は金の神、秋を司り、守を司る。
> 家学を承け、師門を習い、知るところと守るところをもって、出会う人のために、安らぐ一隅を立てる。

**範例二｜服務區塊引言**

普通寫法：

> 我們提供專業的風水堪輿諮詢服務，幫助您改善家居、辦公環境，提升運勢！

蓐収氣口：

> 風水之學，本為「相形度勢」。
> 看的是地形與氣場，動的是陳設與時機，
> 求的是人與所居之間，恰好的相安。

日文對等：

> 風水の学、本は「形を相し、勢を度る」もの。
> 見るは地形と気の場、動かすは設えと時機、
> 求むるは人と住処との間、ちょうど良き相安なり。

**範例三｜聯絡頁文案**

普通寫法：

> 點擊下方按鈕，立即預約您的專屬諮詢！我們將在24小時內回覆您！

蓐収氣口：

> 如有所詢，可遣信來。
> 我們會在閱讀後，誠實回應。

日文對等：

> ご相談ありますれば、文をお送りください。
> 拝読の後、誠をもってお応えいたします。

### 五、敘事的「不可寫」清單

為避免文案有偏差，特此列明這個品牌**絕不會說的話**：

1. 不承諾任何具體運勢、財富、健康結果
2. 不使用「最」「第一」「唯一」「獨家」這類絕對化詞彙
3. 不展示具體諮詢價格（價格通過聯絡後私下溝通）
4. 不公開任何師承傳度的具體文書、證書、家傳實物
5. 不討論在世人物的具體傳承關係（已故歷史人物如董淳，限於公開史料部分）
6. 不出現任何「成功案例」式的客戶證言（即使是匿名化的）
7. 不展示任何具有靈異色彩、超自然承諾色彩的內容

## 第二章 ｜ 頁面結構地圖

### 一、整體導航邏輯

訪客進入網站後，會經歷一條設計過的路徑——**從疑惑到了解，從了解到信任，從信任到聯絡**。每一頁存在的理由都對應訪客心中的一個問題：

| 訪客內心的問題 | 對應頁面 | 我們在這一頁要做的事 |
|--------------|---------|-------------------|
| 這是什麼？ | 首頁（照壁） | 用 5 秒鐘讓他知道這不是普通網站 |
| 你們是誰？憑什麼？ | 源流（門廳） | 用一個長頁面建立深度信任 |
| 你們做什麼？ | 奉事（正堂） | 把四項奉事說清楚、說準確 |
| 我能讀到什麼？ | 文錄（書齋） | 用文章證明專業深度，留住長期關注者 |
| 你們賣什麼？ | 藏品（文物庫） | 以策展感呈現文創與器物 |
| 怎麼聯絡？ | 通信（山門） | 提供一個有禮、克制的入口 |

---

### 二、頂部導航結構

固定置頂的主導航（中日切換按鈕固定在右上角）：

```
蓐収                                         中｜日
─────────────────────────────────────────────────
  源流    奉事    文錄    藏品    通信
```

**命名思路說明：**

- **「源流」**——取自儒家史學與道教傳承中常用的「考其源流」傳統。「源」是家學的根，「流」是當下的傳承
- **「奉事」**——取「敬事而為人所託」之意，比常見的「服務」要重得多，貼合敬畏感
- **「文錄」**——古籍中常見的詞，意為「文章記錄」
- **「藏品」**——避免電商感，呈現策展氣質
- **「通信」**——書信往來的古意

#### 頁面二 ｜ 源流（about）

**這是整個網站的靈魂頁面，也是最長的頁面。**

訪客來這裡的目的只有一個：**判斷這家公司值不值得信任**。所以這一頁不能像普通公司簡介那樣三段了事，而要像一本薄薄的小冊子，能讓對的人讀完之後沉默良久。

頁面結構如下：

```
═══ 源流 ═══════════════════════════════════════════

序章｜為什麼是「蓐収」
  ─ 名字的釋義（《禮記》《山海經》引文）
  ─ 為什麼選這個名字（守護者，而非招攬者）

一、北辰所指：山東濟寧，董氏一脈
  ─ 山東海岱地區的八主信仰背景（公開史實）
  ─ 天齊廟與大汶口文化遺存（公開史實）
  ─ 董氏家族在當地的儒道傳承簡述
  ─ 家學的核心關懷：「鎮水興文，守土安人」

二、文宗遺風：清代先祖董淳
  ─ 嘉慶年間布政使，從二品
  ─ 三大堪輿善舉：威遠文峰塔、岳池文明塔、合州振興塔
  ─ 《華陽縣志》四十四卷的修纂貢獻
  ─ 「鎮水興文」理念的當代意義

三、東渡：兩個人的選擇
  ─ 董越的學習之路（不涉及具體傳承文書）
  ─ 鲁逸凡的學習之路（理工碩士轉向道學的故事）
  ─ 兩人為共同事業東渡日本，立蓐収於大阪

四、奉事的邊界
  ─ 我們做什麼（四項奉事的概述）
  ─ 我們不做什麼（不承諾運勢、不批命限、不販售符咒類產品）
  ─ 我們的客群（為文化所動心者）

═══════════════════════════════════════════════════
```

**這一頁的視覺設計重點：**

- 全頁採用單欄、窄寬度（最大 640px）的閱讀版式，像一本書
- 中日雙語並列展示，採用上下交替展開（不要左右並排）
- 段落之間用簡單的橫線分隔，不用花哨裝飾
- 引用古籍原文時用框線界欄包圍，帶輕微背景色區分
- 不放任何先人的具體文書照片
- 可以放公開的歷史文物照片（文峰塔、奎閣等省級文物保護單位的公開照片）

**奉事四維的維度劃分：**

- 「相形度勢」管**空間**——地、屋、格局

- 「命理解析」管**人**——人、命、週期
- 「事體諮詢」管**事**——事、變、策

時、空、人、事——四個維度，互不重疊，覆蓋完整。

**每項奉事的詳細子頁**結構：

1. 引文（一句古意定位）
2. 此項奉事的學理本源（家學或師門中的相關淵源）
3. 適用場景（什麼樣的問題適合通過這項奉事處理）
4. 不適用場景（明確邊界，建立信任）
5. 流程說明（諮詢方式、材料準備、所需時間）
6. 通信入口

#### 頁面四 ｜ 文錄（articles）

不是「博客」，而是 **《蓐収文錄》**——一份按主題分類的長期寫作集。

```
  按題類覽：

    學理  ──  術數、風水的學理性內容
    文化  ──  道教、八主信仰、家族與地方文化
    案例  ──  化名脫敏的諮詢觀察（後續擴充）

  ─────────────────────────────────────────────────

  文章列表（按時間倒序）

═══════════════════════════════════════════════════
```

```
  此學重「象數」而輕「占斷」——
  讀的是格局之象，而非未來之數。

  ・開業、簽約、發布、上市等重大事件之擇時

  ・期望通過擇時規避一切風險
  ・將擇時結果視為唯一決策依據
  ・要求預言具體結局或數字
  ・無實際事體，僅為好奇而問

  一、來信，述明事體與所求時段

  三、書面回覆推演結果與時機建議

  四、若所擇時段已過或事體有變，可再起新局
```

```
  命理、人を読むなり。

  読むは人生の格局と周期にして、
  禍福を読むにあらず、まして結末を読むにあらず。

  命を知るは、吉に趨り凶を避くる巧の為にあらず、
  己の**所是**を見定むるが為なり——
  長を知り、短を知り、往くところを知り、止まるところを知る。

  巌牆の下、知る者は立たず——
  運命に押し退けらるるにあらず、
  自ら立たざるを撰ぶなり。



  ─  学理 ─

  命理の学、東西それぞれの体系を有す。
  我ら所需に依り、三套を用ふ：

  **四柱八字**——年月日時の四柱を以て推演し、
  五行の動的平衡と大運流年の節奏を重んず。

  **紫微斗数**——星曜の入宮を以て人生の格局を観、
  図像化せる命盤に各宮の人生課題を呈す。

  **西洋占星**——惑星・宮位・相位を以て推演し、
  心理層面の剖析と当下行運の解読に長ず。

  三套の体系、視座異なり、長ずるところ異なる——
  問ふ者の問ひそのものに依り、合ふ一套または数套を選ぶ。
  畳ねて複雑とせず、各々その能を尽くさしむ。



  ─  適用 ─

  ・自身の性格・長所・短所の深き認識
  ・人生段階の周期判断と規劃の方向
  ・重大なる選択の前、自視座の校正
  ・親子・伴侶・合夥関係における他者の理解
  ・周期性の低潮にある際の心の依処（心理療法の代替に非ず）



  ─  不適用 ─

  ・「絶対に良し」「絶対に悪し」の判を望む問ひ
  ・日付・金額・氏名に至る精確の予言を求むる問ひ
  ・命理の結を以て個人の努を放棄する所以とする問ひ
  ・心理疾患の代替もしくは治療の遅延に類する問ひ



  ─  流程 ─

  一、文を送り、生年月日時と出生地を提す（出来得る限り精確に）

  二、所問の体系と所詢の問ひを確かむ（面談もしくは書面）

  三、盤を起こし、推演し、解析を書す（三日より七日）

  四、書面の解析報を回し、深きの問に応ず



  ─  通  ─

    己の所是を知らんと欲せば、文をお送りください。
```

```
  奉事四維 · 四

  ─  引  ─

  「**人生有大事，須有大事的看法。**」



  ─  釋  ─

  事體，乃事之整體。

  人生中有些事，無法用單一視角應對——
  婚嫁，是家事，亦關乎人與時；

  匯於一事，給出整體的看法。



  ─  學理 ─

  在傳統中國的家學裡，
  家中長者為晚輩裁定大事，從來不是依靠單一術數——
  而是相形、擇時、論命三者並用，
  輔以對人事與世道的整體判斷。

  這份綜合的判斷，本身就是一種失傳已久的家學。

  蓐収的事體諮詢，正是將這份古老的整體視角，
  以當代的方式重新提供——
  不為替你做決定，
  而是讓你**在做決定時，有一份完整的依據**。



  ─  適用 ─

  ・婚姻、生育、教育路徑等家庭重大決策
  ・創業、轉行、合夥、退出等事業重大選擇
  ・移居、置產、留學等跨地域人生轉折
```

## 第四章 ｜ 視覺規範

### 一、設計總原則

整站視覺只遵循一條原則：**像一本宋代刻本古籍**。

宋本書籍的特徵——**素紙、黑墨、單欄、寬白、無裝飾**——恰好與品牌氣質完全一致。所有的視覺決策都圍繞這個比喻展開：

- **紙感**：所有背景都是「絹本」或「宋紙」的色感，不是純白
- **墨感**：所有文字都是「徽墨」的黑，不是純黑
- **界格**：所有分隔線都是宋本「界欄」的單線，不是粗條塊
- **題識**：所有強調用赭石紅，模仿古籍朱筆批註，但**不加粗**
- **白口**：所有區塊間留有大量留白，呼應宋本的「天頭地腳」

### 二、色彩系統

#### 主色板（CSS 變數定義）

```css
:root {
  /* 紙色系 ─ 用於背景 */
  --paper-main:    #F5EFE3;   /* 素絹米白：主背景 */
  --paper-deep:    #EDE5D2;   /* 深絹色：卷二背景、區塊分隔 */
  --paper-dark:    #DDD2BB;   /* 暗絹色：卷三背景 */
  --paper-edge:    #C9BCA0;   /* 紙邊色：邊框、極淡分隔線 */

  /* 墨色系 ─ 用於文字 */
  --ink-main:      #1F1A15;   /* 徽墨黑：主要文字 */
  --ink-mid:       #3A332B;   /* 中墨灰：次要文字 */
  --ink-light:     #6B5C4E;   /* 淡墨灰：輔助說明、頁腳 */
  --ink-faint:     #9E8C7A;   /* 微墨灰：佔位文字、極淡標籤 */

  /* 強調色 ─ 限制使用 */
  --accent-red:    #A0522D;   /* 赭石紅：題識、重點詞 */
  --accent-gold:   #B89968;   /* 金箔黃：極少量點綴 */

  /* 邊框 */
  --border-faint:  rgba(31,26,21,0.08);    /* 極淡邊框 */
  --border-line:   rgba(31,26,21,0.18);    /* 標準邊框 */
}
```

#### 配色使用規則

**主背景 `--paper-main`**：首頁、源流、奉事、文錄、通信、藏品總覽 ── 全部使用，確保整站底色一致。

**深絹色 `--paper-deep`**：卷二（雅玩之品）的頁面背景；章節分隔處的細條帶（高 1rem 左右）；引用框、信息框的內部填色。

**暗絹色 `--paper-dark`**：**僅用於藏品卷三**的背景，暗示「進入更深的所在」。

**徽墨黑 `--ink-main`**：標題、正文主體、按鈕文字。**永遠不要使用純黑 #000000**。

**赭石紅 `--accent-red`** ——使用範圍極嚴格：

允許使用：

- 古籍引文中的書名《》內文字
- 文中專有名詞（如「鎮水興文」「八主信仰」「蓐収為金神」中的「蓐収」）
- hover 狀態下的鏈接文字
- 表單聚焦時的下劃線

絕不使用於：大段文字；警示提示；按鈕填色；整個標題。

**金箔黃 `--accent-gold`**：極少量點綴，僅用於頁面進入時的書法墨點動畫、品牌 Logo 的特殊處理。**不用於文字**。

### 六、動效規範

整站動效的總原則：**像翻書，不像滑動**。

#### 允許的動效

**滾動進入時的內容淡入：**

```css
.fade-in {
  opacity: 0;
  transform: translateY(16px);
  transition: opacity 0.7s ease, transform 0.7s ease;
}
.fade-in.visible {
  opacity: 1;
  transform: none;
}
```

通過 `IntersectionObserver` 監聽 `threshold: 0.1` 觸發。

**hover 過渡：** 顏色變化、邊框顏色變化（不允許位移、縮放、旋轉）。

**首頁進入時的書法字浮現**（核心動效，僅一次）：

- 「蓐収」二字以 SVG 路徑書寫動畫呈現
- 使用 `stroke-dasharray` 與 `stroke-dashoffset` 實現筆觸書寫感
- 持續時間 2.5 秒，緩動函數 `ease-out`
- 只在訪客**首次進入**時觸發，之後切換頁面不再重複

#### 禁止的動效

視差滾動（parallax）；輪播圖（carousel）；自動播放動畫（除首頁書法動畫外）；粒子效果；滑鼠跟隨效果；任何旋轉、彈跳、閃爍。

## 第五章 ｜ 技術選型與交付包

### 一、技術棧推薦

#### 主推方案

```
框架：       Next.js 14 (App Router)
樣式：       Tailwind CSS 3.x
內容：       MDX（用於文錄文章）
表單：       Formspree（無需後端）
部署：       Vercel
版本控制：   GitHub
域名：       通過 Vercel 綁定 jokushu.co.jp（已就緒）
```

#### 為什麼選這個組合

**Next.js 14**：原生支持中日雙語的 i18n 路由（`/zh/...` `/ja/...`）；靜態生成（SSG）保證頁面加載極快，符合「翻書感」的體感；App Router 對嵌套布局的支援，適合「源流頁長文 / 奉事四維子頁」這類層級結構；與 Vercel 的部署整合，零配置上線。

**Tailwind CSS**：CSS 變數可直接映射前述配色系統與字體系統；`gap`、`tracking`、`leading` 等工具類正好對應第四章定義的設計 token；利用 `@apply` 將重複的組件樣式（按鈕、表單）抽出為可復用 class。

**MDX 用於文錄**：文章用 Markdown 撰寫，不需要編輯器；文錄頁的擴展（後續發布新文章）只需在 `/content/articles/` 新建 `.mdx` 文件即可；可由非技術人員直接撰寫新文章。

**Formspree**：通信頁的表單，無需自建後端；提交後直接發郵件到指定地址；免費版每月 50 條提交，足夠初期使用。

#### 不推薦的方案

- **WordPress**——太重，且模板生態與蓐収的視覺氣質完全不匹配
- **純靜態 HTML**——文錄擴展會非常麻煩，每篇新文章都需要手寫 HTML
- **Vue / Nuxt**——技術上可行，但本案的編碼者市場 Next.js 更主流

### 三、關鍵實現要點

#### 1. 中日雙語的處理方式

**路由策略：**

- 默認語言：日文（`/`）
- 中文版：`/zh/`
- 訪客首次進入時，根據 `Accept-Language` header 判斷自動跳轉
- 切換語言保留當前頁面的對應語言版本

**內容組織：**

- **不使用機翻或運行時翻譯**
- 每個頁面的中日兩個版本分別撰寫，作為兩個獨立 JSON 文件
- 文章使用兩個獨立 MDX 文件（`.zh.mdx` 與 `.ja.mdx`）
- 路由路徑保持中日同名

#### 2. 全部頁面文案的獨立性

**極其重要的原則：** 每個頁面的所有文案，都從本策劃文檔導出為 JSON 文件，存放於 `content/pages/`。**頁面組件本身不包含任何中文或日文文字**。

例如 `home.zh.json`：

```json
{
  "hero": {
    "kanji": "蓐収",
    "subtitle1": "蓐収為金神，主秋，主守護。",
    "subtitle2": "承家學，習師門。",
    "scrollHint": "源流"
  },
  "tagline": {
    "main": "承古融今，安身立命。"
  },
  "sourceIntro": {
    "lines": [
      "山東濟寧，董氏儒道世家。",
      "家有古廟，名曰天齊，",
      "可考至元，溯源更深。",
      "清嘉慶間，先祖董淳",
      "以堪輿為一方安文運，",
      "至今文峰塔猶在。"
    ],
    "cta": "讀源流"
  }
}
```

**這樣做的好處：**

- 你和太太未來想修改任何一句文案，只需編輯 JSON 文件，不用碰任何代碼
- 編碼者交付後，內容自主權完整保留
- 將來如需擴展第三語言（英文等），只需新增一份 JSON

#### 3. 首頁書法字動畫的實現

「蓐収」二字的書寫動畫，採用 SVG 路徑 + `stroke-dasharray` 技術：

```jsx
<svg viewBox="0 0 200 100" className="shufa-display">
  <path
    d="M..."  // 「蓐」字的書法路徑
    stroke="var(--ink-main)"
    strokeWidth="2"
    fill="none"
    className="stroke-anim stroke-anim-1"
  />
  <path
    d="M..."  // 「収」字的書法路徑
    stroke="var(--ink-main)"
    strokeWidth="2"
    fill="none"
    className="stroke-anim stroke-anim-2"
  />
</svg>
```

```css
.stroke-anim {
  stroke-dasharray: 1000;
  stroke-dashoffset: 1000;
  animation: write 2.5s ease-out forwards;
}

.stroke-anim-2 {
  animation-delay: 1.2s;
}

@keyframes write {
  to { stroke-dashoffset: 0; }
}
```

**SVG 路徑的獲取：** 委託書法家題字 → 掃描為高清圖片 → 使用 Adobe Illustrator 或 Figma 將筆畫轉為 SVG 路徑。或購買授權書法字體 → 在矢量軟件中輸入「蓐収」 → 描邊轉為路徑導出。

**只在首次訪問時播放：**

```jsx
useEffect(() => {
  const visited = sessionStorage.getItem('jokushu-visited');
  if (!visited) {
    setShouldAnimate(true);
    sessionStorage.setItem('jokushu-visited', 'yes');
  }
}, []);
```

- 修改文案：編輯對應頁面的 JSON 文件
- 新增藏品：在 `content/collections/卷X.json` 中追加數據
- 修改後 `git push` 到 GitHub，Vercel 自動部署
