# 策划执行修订备忘录

本文件记录第一版网站开发过程中，对《蓐収株式会社｜品牌與網站策劃文檔》定稿版 v1.0 的所有偏离与修订。

策划定稿本身不作修改，保持原始设计思考的完整性。本备忘录是策划定稿的补充文件，两者并列阅读。

---

## 修订一｜技术栈变更

**策划原文（§5.1）：** Next.js 14 (App Router) + Tailwind CSS

**实际采用：** Astro 静态站 + 原生 CSS（CSS 变量体系）

**原因：** 项目在策划交付前已建立为 Astro 项目，迁移至 Next.js 的成本大于收益。Astro 的静态生成能力同样满足「翻书感」的页面加载要求，且已有内容集合（articles）基于 Astro 的 content collections 构建。

**影响范围：** 仅影响技术实现层，不影响任何品牌、视觉、文案决策。策划 §4 定义的所有 CSS 变量原样搬入 Astro 项目的 `src/styles/global.css`。

**确认时间：** 2026 年 5 月，项目启动阶段

---

## 修订二｜部署平台变更

**策划原文（§5.4）：** 提及 Vercel 和 Netlify 均可

**实际采用：** Vercel（生产环境已部署，域名已绑定）

**原因：** 项目在开发过程中发现实际绑定的是 Vercel 而非 Netlify。GitHub commit status 确认部署目标为 Vercel。

**连锁影响：** 表单方案从 Netlify Forms（Netlify 平台原生功能）改为 Formspree（平台无关的第三方表单服务）。策划 §5.3.6 原文即提及 Formspree 作为可选方案，此变更在策划允许范围内。

**确认时间：** 2026 年 5 月，步骤 5 执行阶段

---

## 修订三｜中日双语呈现方式变更

**策划原文（§4.4 + §2.5）：**

> 桌面端：中文段落在上，日文段落在下；两段之间以 1px solid rgba(31,26,21,0.08) 细线分隔；细线两侧各留 1.5rem 空白。不做左右并排。

即：每个页面同时展示中日两种语言，上下排列。

**实际采用：** 全站语言切换模式——同一时间只显示一种语言，通过右上角「中｜日」按钮切换。

**原因：**

1. 上下排列使每个页面的滚动长度翻倍，其中一半内容对当前访客无用
2. 源流页和奉事子页本身就是长文页面，翻倍后阅读体验严重下降
3. 策划核心比喻是「宋代刻本古籍」——古籍不会在同一页上下放两种语言
4. 导航栏已有「中｜日」切换 UI，让它真正控制全站语言是更自然的交互

**保留不变的：**

- JSON 文案文件的 `zh` / `ja` 并存结构不变
- 中日文案内容对等、分别撰写（非机翻）的原则不变
- 默认语言为日文的规则不变
- 首次访问根据浏览器 Accept-Language 自动判断的规则不变
- 品牌名「蓐収」和导航项文字在两种语言下不变的规则不变

**实现方式：** 两个语言版本的 DOM 都渲染到页面中，通过 `<html>` 标签上的 CSS class（`lang-zh` / `lang-ja`）控制显隐。语言状态保存至 localStorage。

**确认时间：** 2026 年 5 月 15 日，源流页和奉事页实际预览后确认

## 修订四｜服务体系保持策划四维，不采纳旧任务书五线

**这不是对策划的修订，而是对一个错误偏离的纠正。**

**事件经过：**

开发初期使用了两份非策划团队生成的任务书（「官网开发任务书简版 v1」和「官网开发仕様書 v1」），这两份文档将策划定稿的「奉事四维」（相形度势 / 择时推演 / 命理解析 / 事体咨询）替换为「五大服务」（风水鉴定 / 命理运势 / 道教科仪 / 开运用品 / 事业战略），并新增了独立价格页、FAQ 页、12 字段联系表单等策划未定义的内容。

这两份旧任务书与策划定稿存在系统性偏离，涉及服务体系、视觉系统（深墨金色 vs 素绢米白）、首页结构（九段营销 vs 六屏克制）、定价策略（公开价格表 vs 不展示价格）、联系方式（复杂表单 vs 极简三字段）等全部核心维度。

**纠正措施：**

重新生成了开发任务书 v2，严格基于策划定稿逐章提取开发指令，每条指令标注策划出处。旧任务书已废弃。

**确认时间：** 2026 年 5 月 14-15 日

## 修订五｜藏品页第一版做占位

**策划原文（§2.3 页面五 + §3.5）：** 完整的三卷结构（日用之器 / 雅玩之品 / 昔人之藏），含商品列表、外链跳转、价格展示等。

**实际采用：** 第一版仅做占位页，展示藏品总览引言和三卷名称，标注「準備中」。

**原因：** 商品数据（图片、描述、价格、店铺链接）尚未就绪。策划中藏品页的完整实现依赖外部供应商的商品资料和 Yahoo!ショッピング / 楽天市場的店铺链接，这些在第一版上线时尚不具备。

**后续计划：** 商品数据就绪后按策划 §3.5 的三卷结构和 §3.5 的视觉差异化规则完整实现。

**确认时间：** 2026 年 5 月，路由矩阵阶段
