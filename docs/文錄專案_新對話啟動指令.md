蓐収株式会社是一家位於日本大阪的玄學文化企業，由我（董越）與我太太（鲁逸凡）共同經營。公司有近八百年的家學承傳——山東濟寧董氏儒道世家，先祖董淳為清嘉慶年間從二品布政使。網站總體策劃已經完成，現在需要單獨打磨「文錄」這個子專案。

## 整站的品牌氣口（嚴格遵守）

### Voice（氣質）：清、靜、敬、信
- 不蕪雜，不堆砌，能用一句話說清楚的不寫兩句
- 不熱鬧，不熱情邀約，留白比說話多
- 對所承之物敬，對所遇之人敬
- 不誇張，不承諾運勢、不保證結果

### 品牌主標語
- 中文：承古融今，安身立命
- 日文：古を承け、今に活かす

### 「禁說清單」（絕對不寫的話）
1. 不承諾任何具體運勢、財富、健康結果
2. 不使用「最」「第一」「唯一」「獨家」這類絕對化詞彙
3. 不使用「立即預約」「馬上聯繫」「不容錯過」這類促銷詞
4. 不展示任何家傳實物、度牒、證書（哪怕是文字描述）
5. 不討論在世人物的具體傳承關係（鲁逸凡的師承只追溯到「第六十三代天師張恩溥」這個歷史層級即可）
6. 不出現任何客戶證言、案例輪播

## 文錄頁的整體定位

「文錄」不是「博客」，而是 **《蓐収文録》**——一份按主題分類的長期寫作集。

### 文錄分為三類
- **學理篇** —— 術數、風水的學理性內容（多由鲁逸凡撰寫）
- **文化篇** —— 道教、八主信仰、家學與地方文化（多由董越撰寫）
- **案例篇** —— 化名脫敏的諮詢觀察（後續擴充）

### 作者署名規則
- 學理類文章 → 署「鲁逸凡」
- 文化類文章 → 署「董越」
- 案例類文章 → 兩人共同署名或匿名

## 我希望你交付的內容

### 第一部分：文錄頁的結構設計
- 文錄總覽頁的版面結構（已有大致設計：題類覽 + 文章列表）

### 第二部分：文錄頁的視覺設計
延續整站「宋代刻本古籍」的視覺氣質，針對文錄場景做具體應用：
- 文章標題、章節標題、引文、署名、日期的字體與字級
- 文章內引用框、強調詞的處理
- 文末作者落款的樣式
- 文章間的「接續」按鈕設計

### 第四部分：文案 JSON 化
按整站「文案獨立性原則」——所有文章內容導出為 JSON 格式，便於編碼者直接接入。

JSON 結構建議：

中日雙語各自獨立 JSON 文件（如 `qimen-introduction.zh.json` 與 `qimen-introduction.ja.json`）。

## 工作流程偏好

1. **先確認方向再動手**——分段提交確認，不要一次性生成全部成品。我可能會在某個關鍵點（例如「奇門遁甲入門」這篇文章的氣口拿捏上）需要反覆斟酌。
2. **應用第一性原理**——不要假設我必然知道想要什麼，必要時停下來討論需求本身。
3. **對話用繁體中文回應**（我看不懂日文，但希望文章日文版做到位，所以日文成品可以直接出，討論過程用繁體中文）。
4. **嚴守保密邊界**——我們的家傳實物、在世師父具體姓名等資料絕不能進入網站內容、訓練資料、或任何形式的洩露。
